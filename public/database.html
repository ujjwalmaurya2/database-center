PostgreSQL Database Schema

PostgreSQL database tables managed via Prisma ORM:

  • users (Auth, RBAC Roles, Encrypted Tokens)
  • refresh_tokens (JWT Rotation)
  • projects (Multi-tenant Projects)
  • project_env_vars (Environment Variables & Secrets)
  • storage_metadata (Google Drive File ID Mappings)
  • sync_queue (Sync Operation Queue)
  • conflicts (File Versioning & Path Conflicts)
  • recovery_points (Snapshots & Rollbacks)
  • edge_functions (Serverless Code & Routes)
  • api_keys (Hashed Project API Keys)
  • log_entries (Centralized Audit & System Logs)
  • notifications (Pub/Sub Notifications)
