REST API & Swagger Documentation

OpenAPI interactive documentation is generated automatically and accessible at:

Launch Swagger UI (/api-docs)

GET /health - System health status

GET /ready - DB & Redis readiness probe

GET /metrics - Prometheus exporter

POST /api/v1/auth/register - Register user account

POST /api/v1/auth/login - Email & Password sign-in

POST /api/v1/auth/refresh - Refresh access token

GET /api/v1/auth/me - Authenticated user profile
