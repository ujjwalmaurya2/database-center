Google Drive StorageProvider

Active Provider Plugin: GoogleDriveStorageProvider

DriveBase uses an extensible StorageProvider abstraction. User files are stored directly in their own Google Drive account under the hidden app directory while storage metadata is tracked in PostgreSQL.

✓ StorageProvider Interface: Active

✓ Token Encryption: AES-256-GCM Enabled

✓ Fallback Extension Ready: S3StorageProvider, DropboxStorageProvider, R2StorageProvider
